# Student ePortfolio

A responsive, GitHub Pages-ready portfolio for a York University Lassonde School of Engineering BSc (Honours) Computer Security student. The content uses editable prompts and avoids invented accomplishments.

## Preview locally
Open `index.html` in a browser. No build step or server is required.

## Publish with GitHub Pages
1. Create a GitHub repository and upload the contents of this folder.
2. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Open the Pages URL shown by GitHub after publishing.

## Customize
- Edit page text directly in the matching `.html` file.
- Navigation and responsive styles are in `assets/style.css`; mobile navigation is in `assets/script.js`.
- Add project images to `assets/images/` and documents to `assets/documents/`. Replace starter cards with work you can share and describe accurately.
- To publish a resume, add a reviewed public PDF as `assets/documents/resume.pdf` and change the disabled button in `resume.html` to link to it.
- Replace the `T` monogram with your preferred initials or mark.

## Privacy and attribution
Before publishing artifacts, confirm you have permission to share them, remove confidential or personal information, credit collaborators and sources, and describe your contribution clearly. The co-op description is intentionally general.
